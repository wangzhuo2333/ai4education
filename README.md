# ai4education

A static GitHub Pages site for the IJCNN AI Innovations for Education workshops.

- `index.html` is the Workshop Content page. It contains the full body text of the three supplied Blogger announcements.
- `organizers.html` lists the workshop organizers and chairs. The 2025 list follows the official IJCNN program.
- `assets/` contains the shared style, archive navigation, the ImageGen hero illustration, and the original Blogger portrait.

## GitHub Pages

Copy the contents of this folder to the root of your GitHub repository, including the `.nojekyll` file. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save. All local links are relative, so the same files work under a repository URL or a custom domain.

[GitHub Pages publishing source documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Local preview

Open `index.html` in a browser. No build step is required.
